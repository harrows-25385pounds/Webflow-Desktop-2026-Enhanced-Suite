**Q: Does this tool require an active internet connection?**
A: An internet connection is required for the initial download and to sync projects with your online Webflow account. Once synced, the local editor and preview tools work offline.

**Q: Is this compatible with my existing Webflow projects?**
A: Yes, the suite is designed to import and work with projects created on the Webflow platform. You can link your account to access them directly from the dashboard.

**Q: What are the minimum system requirements?**
